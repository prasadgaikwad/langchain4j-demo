LangChain4j Demo

Interactive streaming demo: /chat.html

REST API

  • POST /api/chat {"message": "..."} - chat with memory
  • POST /api/ask {"message": "..."} - RAG question answering
  • POST /api/agent {"message": "..."} - tool-using agent
  • GET /api/chat/stream?message=... - streaming chat (SSE)
  • POST /api/sentiment {"text": "..."} - few-shot classification
  • POST /api/movie {"text": "..."} - structured extraction
  • POST /api/topics {"text": "..."} - topic list
  • GET /api/template?movie=... - rendered prompt template
  • POST /api/index?path=... - index documents
  • GET /api/search?q=... - semantic search
  • GET /api/store - embedding store stats
  • GET /api/history, GET /api/history/{id}, DELETE /api/history/{id} - DB history

WebSocket

  • ws://localhost:8080/ws/chat - send {"message": "..."}, receive tokens

CLI

The interactive CLI still runs on startup (type quit to exit).
